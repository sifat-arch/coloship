📦 ColoShip Delivery System - API Specification Document

প্রজেক্ট নাম: ColoShip Backend & Frontend Integration
তারিখ: September 2026
উদ্দেশ্য: ফ্রন্টএন্ড ডেভেলপমেন্টের জন্য সম্পূর্ণ API এন্ডপয়েন্ট, রিকোয়েস্ট বডি, রেসপন্স ও রোল স্পেসিফিকেশন।

💡 গ্লোবাল কনফিগারেশন ও হেডার তথ্য
Base URL: http://localhost:5000/api/v1
Headers:
• Content-Type: application/json
• Authorization: Bearer <YOUR_ACCESS_TOKEN> (লগইন করা ইউজারদের জন্য)

📑 সূচিপত্র ও রোডম্যাপ (Phases)

Phase ফোকাস মডিউল অগ্রাধিকার মূল উদ্দেশ্য
Phase 1 Core Frontend Blockers HIGH ফি ক্যালকুলেটর, অ্যাডমিন শিপমেন্ট লিস্ট, নোটিফিকেশন, অ্যাড্রেস CRUD
Phase 2 Courier & Rider Operations MEDIUM কুরিয়ার ড্যাশবোর্ড, টাস্ক গ্রহণ/বাতিল, ডেলিভারি প্রুফ (OTP)
Phase 3 Financial & COD Settlements IMPORTANT রাইডার ক্যাশ ডিপোজিট, মার্চেন্ট পে-আউট, অ্যাডমিন এনালিটিক্স
Phase 4 Extras & Value Addition OPTIONAL প্রিন্ট ইনভয়েস/লেবেল, বাল্ক পার্সেল তৈরি, রিভিউ ও রেটিং

🔴 Phase 1: Core Frontend Blockers (ফ্রন্টএন্ডের জন্য সবচেয়ে জরুরি)

১. শিপমেন্ট মডিউল (Shipment Module)

POST /shipments/calculate-fee Public / Customer

বিবরণ: পার্সেল তৈরির আগে ওজন ও ডেলিভারি টাইপ দিলে তাৎক্ষণিক চার্জ ক্যালকুলেট করে দেখাবে।

Request Body:

{
  "weight": 2.5,
  "deliveryType": "EXPRESS",
  "codAmount": 1500
}

Response (200 OK):

{
  "success": true,
  "statusCode": 200,
  "message": "Delivery fee calculated successfully",
  "data": {
    "baseFee": 120,
    "weightCharge": 30,
    "codFee": 15,
    "totalDeliveryFee": 165,
    "currency": "BDT"
  }
}
PATCH /shipments/:id CUSTOMER

বিবরণ: পার্সেল পিকআপ হওয়ার আগ পর্যন্ত গ্রাহক ডেলিভারি ঠিকানা, বিবরণ বা COD পরিমাণ এডিট করতে পারবে।

Request Body:

{
  "deliveryAddressId": "uuid-here",
  "parcelDescription": "Updated fragile note",
  "codAmount": 1800
}
GET /shipments/stats CUSTOMER

বিবরণ: কাস্টমার ড্যাশবোর্ডে পার্সেলের সারসংক্ষেপ দেখানোর জন্য।

Response (200 OK):

{
  "success": true,
  "data": {
    "totalShipments": 24,
    "pendingPickup": 3,
    "inTransit": 5,
    "delivered": 15,
    "cancelled": 1,
    "pendingCodToReceive": 12400
  }
}

২. অ্যাডমিন শিপমেন্ট ম্যানেজমেন্ট (Admin Shipments)

GET /admin/shipments ADMIN

বিবরণ: অ্যাডমিন প্যানেলে সমস্ত পার্সেল দেখার ও ফিল্টার করার জন্য।

Query Params: ?page=1&limit=10&status=IN_TRANSIT&searchTerm=CLS-2026

Response (200 OK):

{
  "success": true,
  "meta": { "page": 1, "limit": 10, "total": 45, "totalPages": 5 },
  "data": [
    {
      "id": "uuid-1",
      "trackingNumber": "CLS-20260904-A89F",
      "status": "IN_TRANSIT",
      "customer": { "name": "Sifat", "phone": "017XXXXXXXX" },
      "courier": { "user": { "name": "Rider Karim" }, "phone": "018XXXXXXXX" },
      "deliveryFee": 120,
      "codAmount": 2500,
      "createdAt": "2026-09-27T10:00:00.000Z"
    }
  ]
}
PATCH /admin/shipments/:id/status ADMIN

বিবরণ: হাব ম্যানেজার সেন্ট্রাল বা লোকাল হাবে পার্সেল পৌঁছালে স্ট্যাটাস আপডেট করবে।

Request Body:

{
  "status": "AT_ORIGIN_HUB",
  "location": "Dhaka Sorting Hub",
  "description": "Parcel received at sorting warehouse"
}

৩. নোটিফিকেশন মডিউল (Notification Module)

🔔 ডাটাবেজে স্কিমা আছে কিন্তু API ছিল না
নিচের API-গুলো ফ্রন্টএন্ডের বেল আইকন, ড্রপডাউন এবং নোটিফিকেশন পেজের জন্য তৈরি করতে হবে।
Method Endpoint Role বিবরণ
GET /notifications All Users লগইন করা ইউজারের নোটিফিকেশন লিস্ট (Pagination সহ)
GET /notifications/unread-count All Users ফ্রন্টএন্ডের হেডার বেল আইকনে লাল ব্যাজ কাউন্ট দেখাতে (যেমন: 3)
PATCH /notifications/:id/read All Users নির্দিষ্ট কোনো নোটিফিকেশন পড়া হয়ে গেলে Read মার্ক করা
PATCH /notifications/mark-all-read All Users এক ক্লিকে সব নোটিফিকেশন Read মার্ক করা

৪. অ্যাড্রেস ও ইউজার প্রোফাইল (Address & User Profile)

Method Endpoint Role বিবরণ
PATCH /addresses/:id CUSTOMER ঠিকানা আপডেট করা (রোড, বাড়ি, ফোন ইত্যাদি)
DELETE /addresses/:id CUSTOMER ঠিকানা ডিলিট করা (Soft delete)
PATCH /addresses/:id/set-default CUSTOMER ডিফল্ট পিকআপ বা ডেলিভারি ঠিকানা হিসেবে সেট করা
PATCH /user/profile All Users নাম, ফোন নম্বর, মার্চেন্ট কোম্পানির নাম আপডেট
PATCH /user/change-password All Users পুরোনো পাসওয়ার্ড ও নতুন পাসওয়ার্ড দিয়ে পাসওয়ার্ড পরিবর্তন

🟠 Phase 2: Courier & Rider Operations (কুরিয়ার/রাইডার অ্যাপ)

GET /courier/dashboard-stats COURIER

বিবরণ: রাইডার ড্যাশবোর্ডে আজকের ডেলিভারি ও জমা ক্যাশের রিয়েলটাইম তথ্য।

Response:

{
  "success": true,
  "data": {
    "activeTasks": 4,
    "completedToday": 7,
    "pendingCashInHand": 8500,
    "todayEarnings": 450
  }
}
PATCH /courier/assignments/:id/respond COURIER

বিবরণ: অ্যাডমিন কোনো পার্সেল অ্যাসাইন করলে রাইডার তা গ্রহণ (Accept) বা রিজেক্ট (Reject) করবে।

Request Body:

{
  "action": "ACCEPT" // অথবা "REJECT", রিজেক্ট করলে "reason": "Out of delivery area"
}
POST /courier/assignments/:id/fail COURIER

বিবরণ: ডেলিভারি ব্যর্থ হলে কারণ রেকর্ড করা।

Request Body:

{
  "reason": "CUSTOMER_UNREACHABLE", // WRONG_ADDRESS, CUSTOMER_REFUSED
  "note": "Called 3 times, phone switched off"
}
POST /courier/assignments/:id/verify-delivery COURIER

বিবরণ: ডেলিভারি সম্পন্ন করার আগে কাস্টমারের ফোনে পাঠানো OTP রাইডার এন্ট্রি দেবে, যাতে ফ্রড না হয়।

Request Body:

{
  "otp": "452109",
  "collectedAmount": 1500
}

🟡 Phase 3: COD Settlement & Financial Flow (টাকা পয়সার হিসাব)

POST /admin/settlements/courier-deposit ADMIN

বিবরণ: রাইডার দিনের শেষে হাবে ক্যাশ জমা দিলে অ্যাডমিন তা কনফার্ম করবে।

Request Body:

{
  "courierId": "courier-uuid",
  "amount": 8500,
  "shipmentIds": ["uuid-1", "uuid-2"],
  "note": "Received full COD amount for today"
}
POST /admin/settlements/merchant-payout ADMIN

বিবরণ: সফল ডেলিভারিগুলোর COD টাকা মার্চেন্টের বিকাশ বা ব্যাংকে পাঠানোর পর রেকর্ড করা।

Request Body:

{
  "merchantId": "user-uuid",
  "payableAmount": 18200,
  "paymentMethod": "BKASH",
  "transactionId": "TRX987456321",
  "shipmentIds": ["uuid-3", "uuid-4"]
}
GET /admin/dashboard/overview ADMIN

বিবরণ: অ্যাডমিন ড্যাশবোর্ডের গ্রাফ ও মূল মেট্রিক্স।

Response:

{
  "success": true,
  "data": {
    "totalShipments": 1250,
    "deliveredCount": 1100,
    "inTransitCount": 85,
    "totalRevenue": 175000,
    "totalCodCollected": 890000,
    "pendingMerchantPayout": 45000,
    "activeCouriers": 14
  }
}

🖥️ ফ্রন্টএন্ড স্ক্রিনের সাথে API ম্যাপিং চার্ট

Frontend Screen / Page যেসব API কল করতে হবে
Create Parcel (নতুন পার্সেল তৈরি) 1. GET /addresses (পিকআপ ঠিকানার লিস্ট)
2. POST /shipments/calculate-fee (লাইভ ফি ক্যালকুলেশন)
3. POST /shipments/ (পার্সেল তৈরি)
4. POST /payments/initiate (বিকাশ বা COD সিলেক্ট করা)
Customer Dashboard 1. GET /shipments/stats (পার্সেল কাউন্ট ও পেন্ডিং টাকা)
2. GET /shipments/my-shipments?limit=5 (সাম্প্রতিক পার্সেল)
3. GET /notifications/unread-count (হেডার বেল আইকন)
Admin Shipments Table 1. GET /admin/shipments (ফিল্টারিং ও পেজিনেশন)
2. GET /admin/available-courier (অ্যাসাইন করার ড্রপডাউন)
3. PATCH /admin/shipments/:id/assign (কুরিয়ার নির্ধারণ)
Rider Active Tasks Screen 1. GET /courier/assignments?status=ASSIGNED
2. PATCH /courier/assignments/:id/status (Picked Up / Delivered)
3. POST /courier/assignments/:id/verify-delivery (OTP ইনপুট)
